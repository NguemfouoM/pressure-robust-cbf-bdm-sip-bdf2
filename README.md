# Pressure-Robust and Exactly Divergence-Free Mixed Finite Elements for Unsteady Thermally Coupled Brinkman--Forchheimer Flow

Reproducibility repository accompanying the manuscript by **M. Nguemfouo** and **J. K. Djoko**.

## Scope

This repository contains the FEniCSx scripts and numerical data used to support the computational results in the manuscript:

- manufactured-solution convergence;
- exact mass-conservation diagnostics;
- direct gradient-force verification of pressure robustness;
- fixed-mesh BDF2 temporal convergence;
- nonlinear Forchheimer sensitivity on geometrically nontrivial domains.

The numerical method combines BDM velocity, discontinuous pressure, tangential SIP Brinkman diffusion, divergence-conforming upwind momentum transport, conforming temperature approximation, and BDF2 time stepping.

## Important coefficient convention

Two numerical verification blocks use different coefficient choices, exactly as documented in the manuscript.

### Manufactured convergence study

The original coupled space--time manufactured test uses

```text
nu(T)    = 1 + 0.1 T,
kappa(T) = 1 + 0.1 T.
```

The corresponding data are stored in

```text
results/manufactured_convergence.csv
```

### Structural validation tests

The direct pressure-robustness test and the fixed-mesh BDF2 test use the globally bounded laws

```text
nu(T)    = 1 + 0.1 tanh(T),
kappa(T) = 1 + 0.1 tanh(T).
```

Their validated outputs are stored in

```text
results/validation/pressure_robustness.csv
results/validation/temporal_convergence.csv
```

## Reproducible environment

The supplied Dockerfile is based on the stable FEniCSx container and installs the additional plotting/mesh dependencies used by the scripts.

Build:

```bash
docker build -t cbf-fenicsx .
```

Run an interactive container from the repository root:

```bash
docker run --rm -it -v "$PWD":/work cbf-fenicsx bash
```

Inside the container, the scripts can be executed with one MPI rank:

```bash
mpirun -n 1 python3 run_all.py
mpirun -n 1 python3 run_complex_domains.py
mpirun -n 1 python3 validation/pressure_robustness_test.py
mpirun -n 1 python3 validation/temporal_convergence_test.py
python3 validation/make_validation_figures.py
```

The manufactured and complex-domain runs can be computationally more expensive than the plotting/post-processing steps.

## Validation targets

The archived pressure-robustness experiment uses

```text
N = 48, dt = 0.01, tf = 1,
lambda in {0, 1, 1e2, 1e4, 1e6}.
```

The archived fixed-mesh BDF2 experiment uses

```text
N = 64, tf = 1,
dt in {0.04, 0.02, 0.01, 0.005},
dt_ref = 0.00125.
```

The recorded invariance defects remain near solver/roundoff level, while the fixed-mesh temporal EOCs are approximately second order for both velocity and temperature.

## Pressure normalization

Pressure is defined only up to an additive constant. The validation solver selects a representative by pinning one mixed pressure degree of freedom. This scalar gauge does not affect the discrete velocity or the pressure-robustness property. Pressure errors in the manuscript are compared after removal of the discrete mean where appropriate.

## Reproducing manuscript figures

The repository includes the archived publication figures used for the complex-domain and structural-validation studies in `figures/`. New figures can be regenerated by the plotting scripts after recomputing the CSV data.
