# Zenodo deposition workflow

1. Create the GitHub repository using the prepared folder.
2. Push the complete repository to the default branch.
3. Sign in to Zenodo using the account that will own the archive.
4. Connect Zenodo to GitHub and enable this repository.
5. Create the GitHub release `v1.0.0`.
6. Zenodo will archive the release and mint a DOI.
7. Copy the Zenodo DOI into the manuscript's Code/Data Availability statement.
8. Add the DOI to the GitHub README and `CITATION.cff`.
9. For later revised manuscript versions, create `v1.1.0` or `v2.0.0`; Zenodo will preserve all versions under a concept DOI.
